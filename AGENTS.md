# Instrucciones para asistentes de IA

Este repositorio es un asistente financiero que se configura con archivos de texto. Para ayudar a mantenerlo (actualizar la cartera, crear o cambiar alertas, ajustar límites, fuentes o variables, explicar un aviso), sigue [`ia/asistente-financiero/SKILL.md`](ia/asistente-financiero/SKILL.md). Responde en el idioma de la persona.
